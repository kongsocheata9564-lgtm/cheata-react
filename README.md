# Getting Started

1. Clone the Repository -> git clone https://github.com/kongsocheata9564-lgtm/readme-cheery-cheek.git
  
2. Enter the Project Directory ->  cd readme-cheery-cheek

3. Create a React Project Using Vite -> npm create vite@latest . -- --template react

4. Install Dependencies -> npm install

5. Start the Development Server -> npm run dev

6. Open the Application

Open the local URL provided by Vite, usually:

http://localhost:5173/
